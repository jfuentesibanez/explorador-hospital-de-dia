# Explorador del hospital de día

Recurso interactivo en español para un curso de hepatocarcinoma. Permite explorar escenarios ficticios del circuito de Tecentriq IV o SC en combinación con bevacizumab.

Cambia volumen de pacientes, proporción SC y sillones; despliega los ajustes para modificar recursos y tiempos locales. Los cuatro resultados distinguen administración, ocupación de sillón, estancia y atención activa de enfermería.

Incluye dos ejemplos guiados, enlaces para compartir los parámetros de cada escenario, un resumen PDF y un Excel con fórmulas auditables. La web y el Excel se ajustan de forma independiente.

Los datos de actividad son sintéticos. Los tiempos operativos son supuestos editables y los tiempos de administración se fundamentan en las fichas de AEMPS/EMA consultadas el 11/09/2026. Las fuentes completas y los límites del modelo están en «Claves y materiales».

No contiene datos de pacientes ni determina decisiones clínicas. Las diferencias de carga no acreditan ahorro económico ni citas adicionales realizables.

Para utilizarlo sin conexión, descarga el repositorio y abre `index.html` en un navegador. No necesita instalación ni claves.
